# Tandem

A little space for the two of you: a couples app for Android with shared moods, a diary, games, dates, pets and a galaxy that grows with you.

This repository only holds the **releases**. Download the latest APK from the [Releases page](https://github.com/Hytyei/Tandem/releases/latest) and open it on your phone. The app updates itself from here.

The source code is private.
